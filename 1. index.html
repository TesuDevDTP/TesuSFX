Overview

Workflow tối ưu cho editor hiện đại

TesuSFX là một panel dành cho Adobe Premiere Pro giúp bạn truy cập thư viện Sound Effects và Music ngay trong môi trường dựng phim. Không cần chuyển qua nhiều tab hay quản lý thủ công từng file, mọi thứ được gói gọn trong một workflow rõ ràng, nhanh và trực quan.

Với mô hình search, preview, favorites và track selection, bạn có thể tập trung vào dựng âm thanh mà không mất thời gian với các thao tác lặp lại.

Features

Tính năng chính

🔎

Tìm kiếm âm thanh

Tìm kiếm nhanh theo tên, loại âm thanh và từ khóa để lọc ra đúng hiệu ứng cần dùng.

📚

Phân loại thư viện

Quản lý âm thanh theo danh mục rõ ràng như Cinematic, Ambient, Impact, Voice, Motion…

▶️

Preview trực tiếp

Nghe trước từng file ngay trên panel mà không cần rời khỏi timeline hoặc ứng dụng chính.

⭐

Favorites

Ghim những file thường dùng và truy cập nhanh hơn trong các dự án tiếp theo.

🎚️

Track selection

Chọn track đang làm việc trực tiếp từ panel để đưa âm thanh vào dự án đúng nơi cần thiết.

🎵

Tách biệt âm thanh và nhạc nền để dễ chuyển đổi giữa hai loại library trong cùng workflow.

Install

Cài đặt

Yêu cầu hệ thống

  • Windows 10 / 11
  • Adobe Premiere Pro hỗ trợ CEP Extension
  • Library âm thanh đã được cấu hình cho panel

Cài đặt thủ công

  • Clone hoặc tải repository về máy
  • Đặt extension vào thư mục CEP Extensions
  • Bật Developer Mode nếu cần
Đường dẫn cài đặt: 
C:\Program Files (x86)\Common Files\Adobe\CEP\extensions

Hướng dẫn Copy đường dẫn, nhấn Windows + R, dán vào ô Open và chọn Enter.
